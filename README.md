# Quest Games

Combined snapshot of the three speech-therapy game apps. Each subfolder is its own independently-developed and deployed project — this repo exists as a single place to see/clone all three together, not as the source of truth for any of them.

- **vaakmirror/** — camera-based mouth/tongue biofeedback game (frontend + backend)
- **breathquest/** — breath-controlled game (frontend + backend + original pygame prototype in `game/`)
- **phonemequest/** — phoneme/word-level speech game (formerly "Chime")

Source-of-truth repos:
- vaakmirror: https://github.com/darayavahoush/vaakmirror
- breathquest: https://github.com/darayavahoush/breathquest
- phonemequest: (chime's real GitHub repo)

⚠️ This repo is a manual snapshot. Changes here do not automatically sync with the individual repos above, and vice versa — update both if you change something that matters long-term.
